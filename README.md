# Demo de Red Nexa

El sitio de Red Nexa simulado en un solo archivo, con datos de ejemplo: `sitio/index.html`. No necesita servidor; también se abre con doble clic.

Se publica en GitHub Pages con el workflow `.github/workflows/publicar.yml` cada vez que cambia `sitio/` en `main`.

## Actualizar la demo

1. Reemplazar `sitio/index.html` por la versión nueva de `rednexademo.html`.
2. Hacer commit y push a `main`. El workflow la publica en un par de minutos.
